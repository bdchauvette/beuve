# 0025. Diff cards: Alabaster-style themes, curated grammars and lazy mounting

- Status: Accepted; insight annotations removed by [0055](0055-review-folded-into-chat-with-verification.md); layout, the ImpactGate banner and `e` amended by [0042](0042-diff-display-modes-whitespace-variant-and-impact-chip.md) and [0043](0043-inline-edits-become-suggestions.md); highlighting, heights and giant cards by [0050](0050-stable-card-props-cached-heights-and-worker-highlighting.md)–[0052](0052-collapsed-cards-lockfiles-large-and-generated-files.md); chrome and diff colors by [0114](0114-design-tokens-logical-properties-and-diff-color-schemes.md); syntax styles by [0119](0119-syntax-by-weight-and-slant.md); grammars by [0120](0120-grammar-injections-and-more-languages.md)
- Date: 2026-10-28

## Context

ADR 0018 chose `@pierre/diffs` for Zone 2 and fixed the CSP delta, the placement and the build shape. Building it raised questions that constrain later work: what exactly the themes color, which grammars ship and what happens to the rest, how a 300-file review stays responsive, where the header lives when the diff mounts late, and how the cards load without slowing the shell. A real-Electron run (`loadFile`, `file://` ESM chunks) also showed that ImpactGate's parsing in main stalls the renderer's first chunk loads.

## Decision

- **Themes.** `syntax-palettes.ts` holds Nikita Prokopov's Alabaster palette, taken from the Sublime Text originals (tonsky/sublime-scheme-alabaster): light `#f7f7f7`/`#000`, strings `#448c27`, constants `#7a3e9d`, comments red `#aa3731`, definitions `#325cc0`; dark (Alabaster Dark) `#0e1415`/`#cecece`, strings `#95cb82`, constants `#cc8bc9`, comments yellow `#dfdf8e`, definitions `#71ade7`. `to-textmate-theme.ts` turns a palette into a TextMate theme with exactly four colored classes (`comment`, `string`, `constant`, `entity.name`) and one plain rule. Unlike the original we don't grey punctuation or escapes: escapes and placeholders stay string-colored. Grammars tag names at use sites with the same `entity.name.*` scopes as definitions, so the plain rule takes back calls (`meta.function-call entity.name.function`, `entity.name.function.call`/`.support`/`.macro`), type references (`entity.name.type`, with class, interface, alias, enum, struct and trait definitions restored), tags, shell commands and template-literal code. A test tokenizes TypeScript, Go, Rust, Python and shell through Shiki to keep this true. No bold or italics. The card registers `beuve-light` and `beuve-dark` and uses `themeType: 'system'`; light is the designed default. `index.css` gains `--beuve-code-bg` and diff emphasis/bar tokens, and the card maps every `--diffs-*-override` it uses to `--beuve-*`. Dark chrome moved to Alabaster Dark's blue-green blacks so the code and the chrome match.
- **Grammars.** `highlighted-languages.ts` lists what is highlighted, keyed by the language `@pierre/diffs` detects: TypeScript, TSX, JavaScript, JSX, JSON/JSONC, CSS, HTML, Markdown, YAML, shell, Go, Python, Rust. The build replaces `shiki/langs` with lazy imports of exactly these, stubs `shiki/wasm` (oniguruma is never loaded; the JavaScript regex engine highlights) and the libraries' bundled theme catalogs. Any other file renders as plain text through `setLanguageOverride(…, 'text')`, never an unresolved-language error.
- **Lazy libraries.** `@pierre/diffs` and `@pierre/trees` are loaded with `import()` by the first card or tree that needs them. The eager renderer is 106 KiB (Lit and the shell, two files); the libraries, Shiki, the engine and each grammar are lazy chunks under `dist/ui/chunks/`, loaded over `file://` from `loadFile` with no CSP changes beyond ADR 0018's.
- **Header outside the diff.** The card renders its own sticky header (status, path, +/−, the ImpactGate banner) and the peek portal in Lit, and mounts `FileDiff` with `disableFileHeader` below them. The header must exist before the diff mounts, and the banner then stays in view while the file scrolls. Insights are line annotations after the last head line of their range that a hunk shows (`to-insight-annotations.ts`). Ranges the patch doesn't show become file-level annotations (line 0). The annotation renders the same `beuve-agent-insight` element, cached per insight.
- **Navigation.** `j`/`k` step through every hunk of every file (`step-review-position.ts`, a hunkless file is one stop). Each stop selects the hunk's first changed run (`plan-hunk-steps.ts`, from `FileDiffMetadata.hunks`, deletions first) with `setSelectedLines` and scrolls its row into view. The library's `revealLine` only expands collapsed context; it doesn't scroll. Hunk expansion uses `loadDiffFiles` backed by `session:get-file-pair` (ADR 0026).
- **Long streams.** We don't use the library's `Virtualizer`, which owns the scroll container and expects its own item model. The stream instead runs two `IntersectionObserver`s on its scroll body. Cards within 1200 px of the viewport mount their diff, and cards beyond 6000 px unmount it (`cleanUp()`) and keep a placeholder of their measured height (an estimate before the first mount), so scrolling doesn't jump. Cards are observed after they have rendered their placeholders.
- **ImpactGate waits for the first diff.** Parsing runs on main's thread, which also serves the renderer's `file://` loads, so the renderer asks `session:get-impact` once the first card emits `beuve-diff-rendered`, or after 1.5 s.

## Consequences

Diffs read like Alabaster: what's colored means something, and the four rules are easy to remember. Synthetic 300-file review (900 hunks), measured in Electron under Xvfb: cards appear within about 0.3 s and the first highlighted rows about 1.0 s after the review is requested (2.4 s before ImpactGate was deferred). 10 cards are mounted at any time while scrolling the full 224 000 px stream, about 7 600 elements across shadow roots, JS heap 12 to 21 MiB, worst frame 60 ms. Without unmounting, all 300 stayed mounted, at about 104 000 elements. A grammar outside the curated list needs a line in `highlighted-languages.ts` (and its scopes checked against the theme test). The JS regex engine can't run a few grammars exactly as oniguruma would; those render with small mistakes rather than failing. The first card pays for loading Shiki and its grammar, about 0.2 to 0.6 s. Interdiffs render the same patch text with nothing special. Inline edit (`e`) is still out of scope.

## Amendment 2026-10-30: no insight annotations

ADR 0055 removes agent insights from the cards. Line annotations now carry staged URA markers and the composer only (`to-head-side-annotations.ts`, formerly `to-insight-annotations.ts`); `beuve-agent-insight` is gone. The violet the insights used is the `--beuve-violet` token.
